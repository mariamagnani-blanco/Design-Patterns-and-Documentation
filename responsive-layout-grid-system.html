Responsive Layout Grid System — grid overlay

Regla:
Wide fills 100% of its region (tables, KPI/card grids) Narrow ~half its region, full only on Mobile (forms, text, option-row lists, toggle lists) Flow a Full-Page Flow locks one region-width for every step, chosen by whichever step needs the most — centered when every step actually fits that width, left-aligned when they can't be unified (so the container doesn't jump side to side) Compositions (Split-intro, Main+Aside) assign zone widths above this — X/Y then applies inside each zone, recursively.
